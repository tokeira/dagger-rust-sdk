## sdk/rust/v1.0.0-beta.11.rust.3 - 2026-08-19

This SDK uses 🚙 Engine + 🚗 CLI version `v1.0.0-beta.11.rust.3`, built from this repository at the release commit; the complete engine ships as a release artifact alongside the crate files.

📦 Released as checked repository artifacts (`dagger-sdk` and `dagger-sdk-macros` crate files plus the complete engine); see sdk/rust/docs/namespace-build.md.

### Fixed
- The complete engine is built from this repository at the release commit — the upstream engine build with the repository and commit substituted — so fork engine corrections (the Void null encoding among them) ship in the release artifact, and the engine reports the release commit it was built from by @iw in https://github.com/iw/dagger/pull/89 \
  Release verification exercises a bare `Void` field (`Container.exportImage`) whose strict null decoding proves the wire correction on the shipped bytes. The `sdk/rust/v1.0.0-beta.11.rust.2` engine artifact predates the correction: its notes carry a note, and its crates pair correctly only with this release's engine.

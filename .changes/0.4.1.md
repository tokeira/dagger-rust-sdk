## 0.4.1 - 2026-11-01

This release targets stock Dagger `v1.0.0-beta.23` engines and CLIs. Applications depend on `tokeira-dagger-sdk = "0.4.1"` from crates.io, which brings `tokeira-dagger-sdk-macros` at the same version, and modules install the runtime from `github.com/tokeira/dagger-rust-sdk/runtime@v0.4.1`.

### Added
- A module's arguments, results and fields can be Core enums and scalars, such as `NetworkProtocol`, `Platform`, `Json` and `Bytes`, as a Go module's can. An enum crosses the boundary as the name of its member and accepts the engine's aliases for it, and a scalar keeps its exact text. A default names an enum member, as in `#[dagger(default = NetworkProtocol::Udp)]`, or gives a scalar's text as a string literal, and generation refuses a default that is not one of the enum's members, or a `Json` default that is not JSON text by @iw in https://github.com/tokeira/dagger-rust-sdk/pull/42

### Fixed
- Generation no longer fails for a module whose object field or interface method names a Core type that none of its functions takes or returns, such as `#[dagger(field)] source: Directory`. It failed with "generated module assets could not be rendered" and no location by @iw in https://github.com/tokeira/dagger-rust-sdk/pull/42
- When the engine refuses a module's registration, for example because a function does not have the shape its role requires, the command that loaded the module showed only `Error: Dispatch(Registration(RegistrationError { source_present: true, .. }))`. It now shows the engine's reason by @iw in https://github.com/tokeira/dagger-rust-sdk/pull/42

### Experimental
- A module function with `role = "agent"` is an agent function, as a Go function marked `+agent` is, so `dagger agent` composes the module's expertise into its conversation. The engine checks the function's shape when it loads the module: its one required `Llm` argument is the conversation, and it returns the conversation it extends. The role is experimental, as is Dagger's `Function.withAgent` by @iw in https://github.com/tokeira/dagger-rust-sdk/pull/42
